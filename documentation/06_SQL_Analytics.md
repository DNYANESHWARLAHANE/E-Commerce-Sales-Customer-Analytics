# SQL Analytics

## 1. Overview

SQL was used as the business-analysis layer of the E-Commerce Sales &
Customer Analytics project.

The SQL workflow was implemented in MySQL using the `ecommerce_analytics`
database.

SQL was used to analyze:

- Overall sales performance
- Data quality
- Monthly sales
- Product performance
- Geographic performance
- Customer performance
- Repeat purchasing behavior
- Customer revenue concentration
- Customer value
- RFM segmentation
- Customer segment performance
- High-value at-risk customers
- Final project reconciliation

The SQL analysis works from the cleaned transaction dataset and separates
transaction-level analysis from customer-level analysis.
