# E-Commerce Sales & Customer Analytics

An end-to-end data analytics portfolio project that analyzes e-commerce sales, customer behavior, product performance, customer segmentation, business risk, geography, and time-based sales patterns.

The project combines **Python, SQL, and Power BI** to transform raw transactional data into business-focused insights and an interactive analytical dashboard.

---

## 📌 Project Overview

This project analyzes the **Online Retail II** transactional dataset to understand:

- Overall sales performance
- Revenue and order trends
- Product performance
- Customer purchasing behavior
- Repeat vs one-time customers
- Customer value
- RFM-based customer segmentation
- Customer risk and revenue exposure
- Geographic sales performance
- Time-based sales patterns
- Business opportunities and customer retention priorities

The project follows an end-to-end analytics workflow:

**Raw Data → Data Cleaning → Python Analysis → SQL Analysis → RFM Segmentation → Power BI Dashboard → Business Insights**

---

## 🎯 Business Objective

The main objective is to build a complete analytical solution that helps answer:

- How much revenue did the business generate?
- How many orders and units were sold?
- Which products generate the most revenue?
- Which products have the highest sales volume?
- Which customers generate the most value?
- How many customers are repeat customers?
- Which customer segments contribute the most revenue?
- Which customers are potentially at risk?
- How much revenue is associated with at-risk customers?
- Which countries generate the most sales?
- At what times is sales activity highest?
- How can customer and sales data support business decisions?
